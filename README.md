# 📊 Pan-India Trainer Reimbursement & Claims Analytics Dashboard
## 📌 Project Overview
This project is an interactive Excel-based MIS & Data Analytics Dashboard designed to analyze trainer reimbursement and claim data across multiple regions in India.
The dashboard transforms raw operational claim data into meaningful business insights through KPI tracking, regional analysis, monthly trends, trainer-wise analysis, and expense-head analysis.
The project demonstrates practical skills in Microsoft Excel, Data Cleaning, Data Analysis, KPI Reporting, Dashboard Development, Pivot Tables, Excel Formulas, Data Visualization, and MIS Reporting.

## 🎯 Business Objective

The primary objective of this dashboard is to provide management with a centralized view of reimbursement performance and help answer questions such as:

- How many claims have been submitted?
- What percentage of claims have been approved?
- What is the total claimed amount?
- What is the total approved amount?
- Which regions have the highest reimbursement amounts?
- Which trainers have the highest approved amounts?
- Which expense heads contribute most to total reimbursement?
- How does reimbursement vary month-wise?
- Which areas require further monitoring?
- How much amount is exceeding the defined limit?

# 🔍 Key Dashboard Analysis
## 1. Region-wise Analysis

The dashboard compares approved reimbursement amounts across different regions.

This helps management identify:

- High-spending regions
- Low-spending regions
- Regional reimbursement patterns
- Areas requiring further investigation

## 2. Month-wise Analysis

Monthly reimbursement trends are visualized to understand changes in approved amounts over time.

This can help management monitor:

- Monthly spending
- Increasing/decreasing reimbursement trends
- Periodic fluctuations
- Budget utilization

## 3. Trainer-wise Analysis

The dashboard provides trainer-level reimbursement analysis.

Management can identify:

- Highest reimbursement amounts
- Lowest reimbursement amounts
- Individual contribution to total reimbursement
- Trainers requiring additional review

## 4. Expense Head Analysis

Reimbursement is categorized into different expense heads such as:

- Bus
- Cab
- Courier
- DA
- ILP
- LC
- Mobile
- RT
- Stationery
- Train

This provides visibility into where the reimbursement budget is being utilized.

## 5. Interactive Filters

The dashboard includes interactive filtering capabilities for:

- Date
- Month
- Trainer
- Region
- Expense Head

This allows users to drill down from overall management-level information to specific operational details.
