# 📊 Pan-India Trainer Reimbursement & Claims Analytics Dashboard
## 📌 Project Overview
This project is an interactive Excel-based MIS & Data Analytics Dashboard designed to analyze trainer reimbursement and claim data across multiple regions in India.
The dashboard transforms raw operational claim data into meaningful business insights through KPI tracking, regional analysis, monthly trends, trainer-wise analysis, and expense-head analysis.
The project demonstrates practical skills in Microsoft Excel, Data Cleaning, Data Analysis, KPI Reporting, Dashboard Development, Pivot Tables, Excel Formulas, Data Visualization, and MIS Reporting.

## 🎯 Business Objective

The primary objective of this dashboard is to provide management with a centralized view of reimbursement performance and help answer questions such as:

- How many claims have been submitted?
- What percentage of claims have been approved?
- What is the total claimed amount?
- What is the total approved amount?
- Which regions have the highest reimbursement amounts?
- Which trainers have the highest approved amounts?
- Which expense heads contribute most to total reimbursement?
- How does reimbursement vary month-wise?
- Which areas require further monitoring?
- How much amount is exceeding the defined limit?
