# 📊 Pan-India Trainer Reimbursement & Claims Analytics Dashboard
## 📌 Project Overview
This project is an interactive Excel-based MIS & Data Analytics Dashboard designed to analyze trainer reimbursement and claim data across multiple regions in India.
The dashboard transforms raw operational claim data into meaningful business insights through KPI tracking, regional analysis, monthly trends, trainer-wise analysis, and expense-head analysis.
The project demonstrates practical skills in Microsoft Excel, Data Cleaning, Data Analysis, KPI Reporting, Dashboard Development, Pivot Tables, Excel Formulas, Data Visualization, and MIS Reporting.
